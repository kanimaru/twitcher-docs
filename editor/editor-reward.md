# Editor Reward

Twitcher adds a reward inspector for Twitch Rewards.
You can load and create Twitch Rewards via Inspector.

![Reward Inspector](/editor-reward.png)

There is also a mass download button for all rewards in the Twitcher Setup:

![Import in Twitcher Setup](/editor-reward-2.png)

Also, be aware when testing the reward system; it seems that the "Temporary Information" is not very reliable 
from Twitch Side / they don't provide the data the documentation says they do.

## Restrictions

- Be aware that you only can edit rewards that were created via Twitcher, all other rewards are read-only.
- You can only change the icons via [Twitch UI](https://dashboard.twitch.tv/viewer-rewards/channel-points/rewards)
